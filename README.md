# Tenora — legal documents

Public legal pages for the [Tenora](https://play.google.com/store/apps/details?id=app.tenora.android) Android app,
published via GitHub Pages so they have a stable, publicly reachable URL for the Google Play Console listing.

- Privacy Policy (English): https://mixerua.github.io/tenora-legal/
- Политика конфиденциальности (русский): https://mixerua.github.io/tenora-legal/privacy-ru.html

The app's own source code lives in a separate, private repository.
